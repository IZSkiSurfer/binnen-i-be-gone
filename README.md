# Binnen-I be gone

An unofficial continuation of **Binnen-I be gone**, a browser extension that converts gender-inclusive spelling on German-language websites into conventional forms.

## Project goals

- Preserve the original text-replacement functionality.
- Fix bugs and improve stability on dynamic websites.
- Maintain compatibility with Microsoft Edge and Google Chrome.
- Keep maintenance and source changes transparent.

## Project status

The upstream baseline is version 3.1.1. The maintained source is now version 3.1.2. Browser runtime testing is pending.

## Installation

### Chrome and Edge

Download the appropriate ZIP from [GitHub Releases](https://github.com/IZSkiSurfer/binnen-i-be-gone/releases), when available, or use the repository source.

1. Clone this repository or download and extract a release package.
2. Disable any previously installed copy of Binnen-I be gone.
3. Open `edge://extensions/` in Microsoft Edge or `chrome://extensions/` in Google Chrome.
4. Enable **Developer mode**.
5. Select **Load unpacked** and choose the directory containing `manifest.json`.
6. Reload affected websites.

Unpacked extensions do not receive automatic browser-store updates. Update the local files and reload the extension to install a newer version.

### Firefox

The Firefox XPI generated by CI is unsigned. For temporary testing, open `about:debugging#/runtime/this-firefox` and select **Load Temporary Add-on**, then choose the XPI. Normal installation requires Mozilla signing.

## Building and releasing

Run `python3 scripts/package.py` to generate all three browser packages in `dist/`. GitHub Actions builds packages on pushes to main and publishes them with checksums when a matching version tag (such as `v3.1.2`) is pushed.

## Contributing

[Bug reports](https://github.com/IZSkiSurfer/binnen-i-be-gone/issues) and pull requests are welcome. Please include the browser and extension versions, steps to reproduce, the affected website if shareable, and relevant developer-console errors. Remove personal information from logs and screenshots.

Keep changes focused and document intentional changes to text-replacement behaviour.
